# SilentStream · 112호

[웹페이지](https://JonathanBlackDoctor.github.io/silentstream-112-playlists/)

최근 30일(한국 시간, 오늘 포함)의 수업 재생목록. 날짜별 링크 복사와 YouTube 열기를 제공합니다. 흑백 디자인과 간단한 네 자리 화면 잠금을 사용합니다.

## 자동 갱신

GitHub Actions가 매시간 13분에 기존 공개 피드의 최신 5수업일을 읽어 월간 목록에 누적합니다. 데이터 변경이 있을 때만 커밋·배포합니다. 예약 실행은 GitHub 상황에 따라 지연될 수 있습니다. AI 작업자, API 키, 별도 유료 서비스를 사용하지 않습니다.

목록은 2026-11-16 기존 M112 화면에서 날짜별 이력 21개를 확인해 시작했습니다. 수집 작업을 5수업일 이상 중단하면 누락 구간을 기존 날짜별 이력에서 보충해야 합니다.

## 실행

- `npm run dev`: 로컬 미리보기, http://127.0.0.1:4312/
- `npm test`: 날짜 경계·안전한 URL·데이터 병합 검증
- `npm run sync`: 공개 피드 수집. 변경이 없으면 파일을 쓰지 않음
- `npm run build`: 배포 파일만 dist/에 복사

라이브러리 설치 없이 Node.js 22 이상에서 실행할 수 있습니다.

## 화면 잠금

사용자가 선택한 간단한 화면 잠금입니다. SHA-256 비교값만 소스에 포함하며 비밀번호 평문은 넣지 않습니다. 공개 소스와 JSON은 직접 열 수 있고 네 자리 값은 추측·우회할 수 있으므로 서버 인증이나 비공개 정보 보호 수단은 아닙니다.

한 번 입장하면 비밀번호 대신 입장 여부만 현재 브라우저의 localStorage에 저장합니다. 같은 브라우저·프로필에서는 탭이나 브라우저를 닫았다 열어도 다시 입력하지 않습니다. 자물쇠 버튼을 누르면 저장된 기록을 지우고 열려 있는 다른 탭도 잠급니다. 기존 열린 탭의 입장 기록은 자동 이관합니다. 다른 브라우저·시크릿 모드·사이트 데이터 삭제 후에는 다시 입력해야 합니다. 저장소 사용이 차단돼도 현재 페이지에서는 입장할 수 있습니다.

기존 사일런트스트림 서버, 비공개 저장소, 기기 제어·계정 인증은 변경하지 않습니다.
