# SilentStream · 112호

최근 30일(한국 시간, 오늘 포함)의 날짜별 YouTube 수업 재생목록입니다. 각 목록의 링크 복사와 YouTube 바로가기를 제공합니다.

## 현재 단계

디자인 4종을 로컬에서 비교 중입니다. 사용자가 디자인을 선택한 뒤 새 공개 GitHub 저장소와 GitHub Pages를 만들 예정이며 아직 생성·게시하지 않았습니다. 기존 m112-archive 저장소와 운영 서버는 수정하지 않았습니다.

- `npm run dev`: http://127.0.0.1:4312/design-review/ 비교 화면. 목록/비밀번호 화면 전환과 크게 보기 제공.
- `npm test`: KST 날짜 경계, 30일 포함 범위, URL 안전성, 목록 병합 검증.
- `npm run sync`: 기존 공개 읽기 전용 피드에서 최신 5개 수업일 수집. 기존 월간 자료와 합치며 변경이 있을 때만 파일을 갱신.
- `npm run build`: 사이트 파일만 dist/에 복사. 검토용 화면과 미리보기 잠금 해제 스크립트는 배포에 포함하지 않음.

## 데이터와 자동 갱신

2026-11-16 인증된 기존 M112 화면의 날짜별 이력에서 2026-10-19~11-16 재생목록 21개를 확보했습니다. 공개 데이터에는 호실, 날짜, 준비 상태, YouTube URL만 포함합니다.

선택 후 GitHub Actions를 매시간 실행해 기존 공개 피드를 누적 수집하고 Pages에 반영할 예정입니다. 현재 워크플로는 아직 등록하지 않았습니다. AI 작업자나 외부 유료 API를 사용하지 않습니다. 예약 실행은 GitHub 환경에 따라 지연될 수 있으며, 공개 피드가 최근 5수업일만 제공하므로 수집 작업을 장기간 중단하면 누락 구간을 기존 인증 화면에서 보충해야 합니다.

## 화면 잠금

사용자가 선택한 간단한 브라우저 화면 잠금입니다. 소스에는 비밀번호의 SHA-256 비교값만 둡니다. 네 자리 값은 추측·우회할 수 있고 공개 JSON도 직접 열 수 있으므로 서버 인증이나 비공개 자료 보호 기능이 아닙니다. 브라우저 탭 세션 동안 입장 상태를 유지하며 잠그기 버튼으로 해제합니다. 실제 인증 토큰이나 기기 제어 정보는 이 저장소에 넣지 않습니다.
